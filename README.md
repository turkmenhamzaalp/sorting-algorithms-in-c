# Sorting Algorithms in C

This repository contains C implementations of fundamental sorting algorithms developed as part of Computer Engineering Data Structures coursework.

## 📂 Algorithms Included

| Algorithm | File | Best Case | Average Case | Worst Case | Space Complexity |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Bubble Sort** | `Bubblesort.c` | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ |
| **Selection Sort** | `selectionsort.c` | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ |
| **Insertion Sort** | `insertionsort.c` | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ |

## 🚀 Compilation and Execution

To compile and run any of the algorithms using `gcc`:

```bash
gcc insertionsort.c -o insertionsort
./insertionsort
